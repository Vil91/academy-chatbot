# Правила проекта для Gemini (backend)

Ты пишешь **только бэкенд** (Node + Express + TypeScript). Дизайн и фронтенд делает Claude — не трогай.

## Контекст
Читай `PRD.md` (раздел 4–6) и `PLAN.md` (Этап 2). База знаний — в `/knowledge/*.md`.

## Технические рамки
- Express + TypeScript + SQLite (better-sqlite3). Структура БД — по PRD §4.
- RAG: грузить `/knowledge/*.md`, бить на чанки, эмбеддинги в память, cosine-поиск. Внешнюю vector-БД не поднимать.
- LLM: Claude API через `ANTHROPIC_API_KEY` из env. Модель — из env `CHAT_MODEL` (по умолчанию актуальная claude-модель). Не хардкодить ключи.
- Контракт ответа `/api/chat`: `{ text, sources[], lang, confidence, handoff }`. Системный промпт запрещает отвечать вне переданного контекста.
- Общие типы — в `shared/types.ts` (согласовать с фронтом, не ломать).
- CORS: разрешить домен фронта из env `FRONTEND_ORIGIN`.

## Жёсткие правила окружения (иначе сессия agy обрывается)
- Shell-команды только с **относительными путями** от корня проекта.
- **По одной команде за вызов**, без `&&`, `||`, `;`, `|`, `>`.
- Никаких кавычек внутри кавычек; для поиска по коду — встроенные инструменты, не shell grep.
- Файлы/папки со скобками `()[]` в пути не передавать в shell — только инструменты чтения.
- Не вызывать MCP-инструменты (память, внешние сервисы).
- Разрешённые npm-команды писать дословно (`npm install`, `npm run build`, `npm test` и т.п.).

## Критерий готовности этапа
- Сервер стартует, миграции/сид отрабатывают, все эндпоинты из PRD §6 отвечают (проверка curl), типы сходятся с фронтом.
