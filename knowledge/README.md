# База знаний Academy Chatbot

Это «одобренный контент», из которого бот отвечает (RAG). Только публичная информация академии —
никаких личных переписок и персональных данных студентов.

Файлы:
- `courses.md` — программы и направления.
- `schedule.md` — расписание занятий и аудитории.
- `faq.md` — частые вопросы (поступление, оплата, посещаемость, экзамены).
- `contacts.md` — контакты и каналы связи.

Источник данных: публичные анонсы академии и официальный список проектов Fellowship Program (ноябрь 2026).
Факты требуют проверки у координатора перед «боевой» сдачей — часть значений (цены, точные даты наборов) помечена `⟨уточнить⟩`.
